저장 상태

지도 종류

카카오 지도·내비: developers.kakao.com → 내 애플리케이션 → 앱 선택 → [앱] → [플랫폼 키] → JavaScript 키의 대표 키 카드를 눌러 상세로 들어간 뒤, JavaScript SDK 도메인에 이 앱의 주소(예: https://아이디.github.io)를 등록하세요. 같은 화면의 JavaScript 키 값을 복사해 위에 붙여 넣습니다. 도메인은 키마다 따로 등록됩니다.

네이버 지도: 네이버 클라우드 플랫폼 콘솔에서 Maps → Application 등록, Web Dynamic Map 선택, Web 서비스 URL에 같은 주소를 등록한 뒤 Client ID를 넣으세요. 결제 수단 등록이 필요합니다.

카카오내비 길안내도 같은 JavaScript SDK 도메인 등록을 사용합니다. 휴대폰에 카카오내비 앱이 없으면 설치 화면이 열립니다.

주소를 등록하지 않으면 인증 오류가 나고, 그때는 기본 지도로 자동 전환됩니다.

우버 기사 앱과는 연결되지 않습니다. 우버의 기사용 API는 승인제이고 픽업 좌표를 주지 않기 때문에, 이 앱은 휴대폰 GPS로 직접 기록합니다.

기록은 이 휴대폰 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우면 사라지니 일주일에 한 번 백업 파일을 받아 두세요.

주행 경로는 화면이 켜져 있을 때만 기록됩니다. 브라우저를 내리거나 화면이 꺼지면 위치 수신이 멈출 수 있으니, 기록 중에는 이 화면을 켜 두세요.

운전 중에는 누르지 마세요. 승객을 태우기 전이나 신호 대기가 아닌 완전 정차 상태에서만 조작하세요.
